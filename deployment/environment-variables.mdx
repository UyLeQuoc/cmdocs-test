# Environment Variables

Set environment variables to customize your build process.

## Build-time Variables

Variables available during the build process:

| Variable | Description |
|----------|-------------|
| `CMDOCS_SITE_NAME` | Site name from docs.json |
| `CMDOCS_BASE_URL` | Base URL of the site |
| `NODE_ENV` | Always `production` during builds |

## Setting Variables

Variables can be set per-environment in the Dashboard:

1. Go to **Project → Settings → Environment Variables**
2. Add key-value pairs
3. Choose which environments to apply them to

## Secrets

Sensitive values are encrypted at rest and never exposed in build logs.
