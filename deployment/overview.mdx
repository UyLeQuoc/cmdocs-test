# Deployment Overview

cmdocs generates a **static HTML site** that can be deployed anywhere static files are served.

## Build Output

Run the build command to generate a static site:

```bash
cmdocs build --source ./my-docs --output ./out
```

This produces a directory of static HTML, CSS, and JavaScript files ready for any web server:

## Dashboard Deployments

The cmdocs dashboard provides:

- **Git integration** — Connect a GitHub repository
- **Automatic builds** — Triggered on push to your configured branch
- **Environment management** — Production, staging, and preview environments
- **Subdomain routing** — Each environment gets a unique subdomain
- **Build logs** — Real-time build status and error reporting
- **Preview screenshots** — Automatic screenshots of deployed sites

### Setting Up

1. Sign in to the [cmdocs dashboard](https://cmdocs.dev)
2. Create a new project
3. Connect your GitHub repository
4. Configure the docs path (where `docs.json` lives)
5. Trigger your first deployment

The dashboard will clone your repo, run the build pipeline, and serve the output on a subdomain like `my-docs.cmdocs.commandoss.com`.
