# Build Errors

Common build errors and how to resolve them.

## EISDIR Error

```
Error: EISDIR: illegal operation on a directory
```

This happens when a route path conflicts between a file and directory. Check for pages that share names with folder paths.

## TypeScript Errors

```
Type error: Cannot find module...
```

Ensure all imports in your MDX files reference valid components. The build uses strict TypeScript checking.

## Missing Dependencies

If the build fails with module not found errors, ensure your `package.json` lists all required dependencies.

## Build Timeout

Builds that exceed 5 minutes are automatically cancelled. Optimize large sites by:

- Reducing image sizes
- Limiting the number of dynamic imports
- Using static generation where possible
