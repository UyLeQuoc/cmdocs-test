# Self-Hosted Deployment

cmdocs produces static HTML that can be served by any web server. Here's how to deploy on common platforms.

## Build Your Site

```bash
cmdocs build --source ./my-docs --output ./out
```

The `out/` directory contains your complete static site.

## Deployment Targets

<Tabs items={["Nginx", "Docker", "Caddy", "Node.js"]}>
  <Tab value="Nginx">
    ```nginx
    server {
      listen 80;
      server_name docs.example.com;
      root /var/www/docs;

      location / {
        try_files $uri $uri.html $uri/index.html =404;
      }

      location /_next/static/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
      }
    }
    ```

    Copy the `out/` contents to `/var/www/docs`:
    ```bash
    rsync -avz out/ user@server:/var/www/docs/
    ```
  </Tab>
  <Tab value="Docker">
    ```dockerfile
    FROM nginx:alpine

    # Copy the static site
    COPY out/ /usr/share/nginx/html/

    # Custom nginx config for Next.js static export
    COPY nginx.conf /etc/nginx/conf.d/default.conf

    EXPOSE 80
    ```

    Build and run:
    ```bash
    cmdocs build --source ./my-docs --output ./out
    docker build -t my-docs .
    docker run -p 8080:80 my-docs
    ```
  </Tab>
  <Tab value="Caddy">
    ```caddy
    docs.example.com {
      root * /var/www/docs
      try_files {path} {path}.html {path}/index.html
      file_server

      @immutable path /_next/static/*
      header @immutable Cache-Control "public, max-age=31536000, immutable"
    }
    ```
  </Tab>
  <Tab value="Node.js">
    Use the `serve` package:
    ```bash
    npx serve out -p 3000
    ```

    Or with Express:
    ```javascript
    const express = require('express');
    const app = express();
    app.use(express.static('out'));
    app.listen(3000);
    ```
  </Tab>
</Tabs>

## Important: File Extension Handling

Next.js static export generates `.html` files at the root level (e.g., `docs.html` instead of `docs/index.html`). Your web server must be configured to handle this:

```
Request: GET /docs
Try:     /docs → /docs.html → /docs/index.html → 404
```

The Nginx and Caddy configs above include this handling via `try_files`.

## CI/CD Integration

### GitHub Actions

```yaml
name: Deploy Docs
on:
  push:
    branches: [main]
    paths: ['docs/**']

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
      - run: npx cmdocs build --source ./docs --output ./out
      - name: Deploy
        run: rsync -avz out/ user@server:/var/www/docs/
```
