# Theme Configuration

Customize your site's visual appearance through the `theme` field in `docs.json`.

## Colors

Set your brand color with the `colors` object:

```json
{
  "theme": {
    "colors": {
      "primary": "#2563EB",
      "light": "#3B82F6",
      "dark": "#1D4ED8"
    }
  }
}
```

| Property | Description |
|----------|-------------|
| `primary` | Main brand color (hex, required) |
| `light` | Override for light mode (optional, falls back to primary) |
| `dark` | Override for dark mode (optional, falls back to primary) |

The primary color is applied to links, active sidebar items, buttons, and other accent elements.

## Dark Mode

Dark mode is **enabled by default**. Users can toggle between light and dark themes.

```json
{
  "theme": {
    "darkMode": true
  }
}
```

Set to `false` to force light mode only.

## Layout

Choose between layout modes:

```json
{
  "theme": {
    "layout": "docs"
  }
}
```

| Value | Description |
|-------|-------------|
| `"docs"` | Standard documentation layout with sidebar (default) |
| `"notebook"` | Wider content area, centered layout |

## Sidebar Options

```json
{
  "theme": {
    "sidebar": {
      "collapsible": true,
      "defaultOpenLevel": 0,
      "tabs": true
    }
  }
}
```

| Property | Description | Default |
|----------|-------------|---------|
| `collapsible` | Allow sidebar groups to collapse | `true` |
| `defaultOpenLevel` | How many levels to expand by default | `0` |
| `tabs` | Show tab navigation in sidebar | `true` |

## Table of Contents

```json
{
  "theme": {
    "toc": {
      "enabled": true
    }
  }
}
```

The table of contents appears on the right side of each page, generated from your headings.

## Additional Options

```json
{
  "theme": {
    "breadcrumb": true,
    "lastUpdated": false
  }
}
```

| Property | Description | Default |
|----------|-------------|---------|
| `breadcrumb` | Show breadcrumb navigation above content | `true` |
| `lastUpdated` | Show "last updated" timestamp on pages | `false` |
