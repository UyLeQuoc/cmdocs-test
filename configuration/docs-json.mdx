# docs.json Reference

The `docs.json` file is the central configuration for your cmdocs site. It defines your site name, theme, navigation, and more.

## Minimal Example

```json
{
  "name": "My Docs",
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [
          {
            "group": "Getting Started",
            "pages": ["index", "quickstart"]
          }
        ]
      }
    ]
  }
}
```

### `navigation` (required)

The navigation object defines the sidebar structure.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Tab Name",
        "groups": [
          {
            "group": "Group Label",
            "pages": ["page-slug", "folder/page-slug"]
          }
        ]
      }
    ]
  }
}
```

See [Navigation Configuration](/docs/configuration/navigation) for details.

### `theme`

```json
{
  "theme": {
    "colors": {
      "primary": "#2563EB",
      "light": "#3B82F6",
      "dark": "#1D4ED8"
    },
    "darkMode": true,
    "breadcrumb": true,
    "lastUpdated": false,
    "layout": "docs"
  }
}
```

See [Theme Configuration](/docs/configuration/theme) for details.

### `seo`

```json
{
  "seo": {
    "title": "My Docs",
    "titleTemplate": "%s — My Docs",
    "description": "Documentation for my project",
    "ogImage": "/og-image.png",
    "canonical": true,
    "robots": "index, follow"
  }
}
```

### `navbar`

```json
{
  "navbar": {
    "title": "My Project",
    "logo": "/logo.svg",
    "github": "https://github.com/owner/repo",
    "links": [
      { "text": "Blog", "href": "https://blog.example.com" }
    ],
    "transparent": false
  }
}
```

The `logo` field accepts either a string path or an object with `light` and `dark` variants:

```json
{
  "navbar": {
    "logo": {
      "light": "/logo-light.svg",
      "dark": "/logo-dark.svg"
    }
  }
}
```

### `footer`

```json
{
  "footer": {

    "links": [

```
