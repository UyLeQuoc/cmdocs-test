# Navigation Configuration

The `navigation` field in `docs.json` controls the sidebar structure. It uses a **tabs → groups → pages** hierarchy.

## Structure

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Tab Name",
        "groups": [
          {
            "group": "Group Label",
            "pages": ["page-slug", "folder/page-slug"]
          }
        ]
      }
    ]
  }
}
```

## Concepts

### Tabs

Tabs are the top-level navigation sections. If you have a single tab, the tab selector is hidden and groups appear directly in the sidebar.

```json
{
  "navigation": {
    "tabs": [
      { "tab": "Guides", "groups": [...] },
      { "tab": "API Reference", "groups": [...] }
    ]
  }
}
```

### Groups

Groups create labeled sections within a tab. Each group has a title and a list of page slugs.

```json
{
  "groups": [
    {
      "group": "Getting Started",
      "pages": ["index", "quickstart", "installation"]
    }
  ]
}
```

Groups appear as collapsible sections with a header label in the sidebar.

### Pages

Page slugs map to MDX files in your project. The slug is the file path relative to your project root, without the `.mdx` extension.

| Slug | File Path |
|------|-----------|
| `"index"` | `index.mdx` |
| `"quickstart"` | `quickstart.mdx` |
| `"guides/setup"` | `guides/setup.mdx` |
| `"api/endpoints"` | `api/endpoints.mdx` |

## Page Ordering

Pages appear in the sidebar in the order they are listed in the `pages` array. This gives you full control over navigation order regardless of filesystem structure.

## Subfolders

When a page slug contains a `/`, cmdocs automatically creates a collapsible subfolder in the sidebar:

```json
{
  "group": "Configuration",
  "pages": [
    "configuration/docs-json",
    "configuration/theme",
    "configuration/navigation"
  ]
}
```

This creates a "Configuration" group with a "configuration" subfolder containing three pages.

## Example: Multi-Tab Navigation

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [
          {
            "group": "Getting Started",
            "pages": ["index", "quickstart"]
          },
          {
            "group": "Guides",
            "pages": ["guides/setup", "guides/advanced"]
          }
        ]
      },
      {
        "tab": "API Reference",
        "groups": [
          {
            "group": "Endpoints",
            "pages": ["api/overview", "api/authentication"]
          }
        ]
      }
    ]
  }
}
```
