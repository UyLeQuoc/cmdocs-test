# Search

cmdocs includes a built-in search powered by Fumadocs' search API.

## Default Search

Search works out of the box — all pages are automatically indexed.

## Customization

Adjust search behavior in `docs.json`:

```json
{
  "search": {
    "enabled": true,
    "placeholder": "Search documentation...",
    "hotkey": "/"
  }
}
```

## Search API

The search endpoint is available at `/api/search` and supports:

- Full-text search across all pages
- Heading-level results
- Fuzzy matching
