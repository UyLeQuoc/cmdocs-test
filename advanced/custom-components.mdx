# Custom Components

Extend your documentation with custom React components.

## Creating Components

Create a component file:

```tsx
// components/VideoEmbed.tsx
export function VideoEmbed({ url }: { url: string }) {
  return (
    <div className="aspect-video rounded-lg overflow-hidden">
      <iframe src={url} className="w-full h-full" allowFullScreen />
    </div>
  );
}
```

## Using in MDX

Import and use directly:

```mdx
import { VideoEmbed } from '../components/VideoEmbed';

<VideoEmbed url="https://youtube.com/embed/..." />
```

## Auto-imported Components

cmdocs automatically imports all Fumadocs UI components. No import statements needed for:

- `<Callout>` — Callout boxes
- `<Card>` — Link cards
- `<Steps>` — Step-by-step guides
- `<Tabs>` — Tabbed content
