# Welcome to cmdocs

**cmdocs** is an open-source, self-hosted documentation platform that transforms your MDX content into a beautiful documentation site — powered by [Fumadocs](https://fumadocs.dev) and [Next.js](https://nextjs.org).

## Why cmdocs?

<Cards>
  <Card title="Zero Migration Effort" description="Drop in your docs.json config and MDX files — cmdocs handles the rest." />
  <Card title="Self-Hosted" description="Deploy on your own infrastructure. No vendor lock-in, no monthly fees." />
  <Card title="Beautiful by Default" description="Powered by Fumadocs UI with dark mode, search, and responsive design built-in." />
  <Card title="Developer-First" description="CLI workflow with hot-reload, static export, and Git-based deployments." />
</Cards>

## How It Works

<Steps>
  <Step>
    **Initialize** — Run `cmdocs init` to scaffold a new documentation project with example content.
  </Step>
  <Step>
    **Write** — Author your documentation in MDX with Fumadocs components. Configure navigation in `docs.json`.
  </Step>
  <Step>
    **Deploy** — Run `cmdocs build` for a static site, or connect your Git repo to the cmdocs dashboard for automated deployments.
  </Step>
</Steps>
