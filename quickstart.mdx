# Quickstart

## Installation

Install cmdocs globally:

```bash
npm install -g cmdocs
```

## Create a new project

```bash
cmdocs init my-docs
cd my-docs
```

## Start developing

```bash
cmdocs dev
```

Open [http://localhost:3000/docs](http://localhost:3000/docs) to see your docs.

## Build for production

```bash
cmdocs build
```

The static site will be generated in the `out/` directory.

## Project Structure

```
my-docs/
├── docs.json          # Configuration
├── index.mdx          # Home page
├── quickstart.mdx     # This page
├── guides/
│   ├── writing-content.mdx
│   └── components.mdx
└── public/
    └── favicon.svg
```

## Next Steps

- Edit `docs.json` to customize your site name, theme, and navigation
- Add new pages by creating `.mdx` files
- Use Fumadocs components like `Callout`, `Card`, `Tabs`, and more
