# MDX Basics

cmdocs uses [MDX](https://mdxjs.com/) — a format that lets you use JSX components inside Markdown documents.

## Markdown Features

All standard Markdown features are supported:

### Headings

```md
# Heading 1
## Heading 2
### Heading 3
```

Headings automatically generate anchor links and appear in the table of contents.

### Text Formatting

```md
**Bold text**
*Italic text*
~~Strikethrough~~
`inline code`
```

### Links

```md
[External link](https://example.com)
[Internal link](/docs/quickstart)
```

### Lists

```md
- Unordered item
- Another item
  - Nested item

1. Ordered item
2. Another item
```

### Blockquotes

```md
> This is a blockquote.
> It can span multiple lines.
```

### Code Blocks

Use triple backticks with a language identifier for syntax highlighting:

````md
```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}
```
````

Supported languages include: `typescript`, `javascript`, `python`, `rust`, `go`, `bash`, `json`, `yaml`, `css`, `html`, and many more.

### Tables

```md
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Cell 1   | Cell 2   | Cell 3   |
| Cell 4   | Cell 5   | Cell 6   |
```

### Images

```md
![Alt text](/images/screenshot.png)
```

Place images in the `public/` directory and reference them with an absolute path.

## JSX Components

The power of MDX is using React components directly in your content. cmdocs auto-imports all Fumadocs components — just use them:

```mdx
<Callout type="info">
  This is an informational callout.
</Callout>
```

See the [Components](/docs/content/components) page for all available components.

## Frontmatter

Every MDX file starts with a YAML frontmatter block:

```md
---
title: Page Title
description: A brief description of this page.
---

# Your content here
```

See [Frontmatter Reference](/docs/content/frontmatter) for all supported fields.
