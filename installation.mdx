# Installation

cmdocs provides a CLI tool for initializing, developing, and building documentation sites.

## Using npx (Recommended)

No installation needed — run directly with npx:

```bash
npx cmdocs init my-docs
npx cmdocs dev
npx cmdocs build
```

## Using Bun

```bash
bunx cmdocs init my-docs
bunx cmdocs dev
bunx cmdocs build
```

## Global Install

Install globally for repeated use:

<Tabs>
  <Tab value="npm">
    ```bash
    npm install -g cmdocs
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bun install -g cmdocs
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm install -g cmdocs
    ```
  </Tab>
</Tabs>

Then use directly:

```bash
cmdocs init my-docs
cmdocs dev
cmdocs build
```

## CLI Commands

| Command | Description |
|---------|-------------|
| `cmdocs init [name]` | Scaffold a new documentation project |
| `cmdocs dev` | Start local dev server with hot-reload |
| `cmdocs build` | Build static HTML for production |

### Common Options

```bash
# Dev server on a custom port
cmdocs dev --port 4000

# Build from a specific source directory
cmdocs build --source ./my-docs --output ./dist

# Specify source directory for dev
cmdocs dev --source ./my-docs
```

## System Requirements

- **Node.js** 18.0 or later (or **Bun** 1.0+)
- **Git** (for deployment integration)
- ~500MB disk space for dependencies
