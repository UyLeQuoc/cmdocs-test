# Components

cmdocs uses [Fumadocs](https://fumadocs.dev) built-in components. The CLI automatically injects the necessary imports when it detects component usage in your MDX files.

## Steps

<Steps>
  <Step>
    ### Install cmdocs
    Run `npm install -g cmdocs`
  </Step>
  <Step>
    ### Create a project
    Run `cmdocs init my-docs`
  </Step>
  <Step>
    ### Start developing
    Run `cmdocs dev`
  </Step>
</Steps>
