# Getting Started Guide

This guide walks you through setting up your first cmdocs project from zero to deployment.

## Prerequisites

Before you begin, ensure you have:

- **Node.js 18+** installed
- **Git** for version control
- A **GitHub** account for deployment integration

## Step 1: Initialize Your Project

Create a new directory and initialize it:

```bash
mkdir my-docs
cd my-docs
git init
```

## Step 2: Create docs.json

The `docs.json` file is the heart of your documentation site. It defines:

- Site metadata (name, description, favicon)
- Theme configuration (colors, dark mode)
- Navigation structure (tabs, groups, pages)

```json
{
  "name": "my-project",
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [
          {
            "group": "Overview",
            "pages": ["index"]
          }
        ]
      }
    ]
  }
}
```

## Step 3: Write Your First Page

Create an `index.mdx` file:

```mdx
---
title: Welcome
description: Welcome to the docs!
---

# Welcome

Your documentation starts here.
```
