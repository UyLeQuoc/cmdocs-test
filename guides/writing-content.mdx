# Writing Content

cmdocs uses MDX, which combines Markdown with JSX components.

## Frontmatter

Every page starts with frontmatter:

```yaml
---
title: Page Title
description: A brief description
---
```

## Markdown Basics

You can use all standard Markdown syntax:

- **Bold text** and *italic text*
- [Links](https://example.com)
- `inline code`

### Code Blocks

Use fenced code blocks with language highlighting:

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}
```

## Images

Place images in the `public/` folder and reference them:

```md
![Alt text](/my-image.png)
```
