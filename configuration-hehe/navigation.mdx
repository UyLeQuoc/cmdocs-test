# Navigation Configuration

The `navigation` field in `docs.json` controls the sidebar structure. It uses a **tabs → groups → pages** hierarchy. The `navbar.links` field controls the navigation links displayed in the header.

## Tabs

### Structure

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Tab Name",
        "groups": [
          {
            "group": "Group Label",
            "pages": ["page-slug", "folder/page-slug"]
          }
        ]
      }
    ]
  }
}
```

### Tab Options

Each tab supports additional customization:

<TypeTable
  type={{
    tab: { description: "Tab display name", type: "string", required: true },
    description: { description: "Description shown in tab dropdown", type: "string" },
    icon: { description: "Lucide icon name (e.g. `BookOpen`) or emoji (e.g. `📚`)", type: "string" },
    url: { description: "Custom URL for the tab (arbitrary URL)", type: "string" },
    unlisted: { description: "Hide from tab list", type: "boolean", default: "false" },
    groups: { description: "Navigation groups", type: "NavigationGroup[]", required: true },
  }}
/>

### Tab with Icon & Description

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Guides",
        "description": "Step-by-step tutorials",
        "icon": "BookOpen",
        "groups": [...]
      },
      {
        "tab": "API Reference",
        "description": "REST API documentation",
        "icon": "Code",
        "groups": [...]
      }
    ]
  }
}
```

When tabs have `description` or `icon`, they appear as a dropdown in the sidebar with rich information instead of plain text.

### Tab Mode

Control how tabs are displayed with `tabMode`:

```json
{
  "navigation": {
    "tabMode": "auto",
    "tabs": [...]
  }
}
```

| Value | Behavior |
|-------|----------|
| `"auto"` | Dropdown (default) — tabs shown as a dropdown in the sidebar |
| `"top"` | Top bar — tabs shown at the top of the sidebar |

### Single Tab Behavior

When only one tab is defined:
- **Without customization** — the tab selector is hidden and groups appear directly in the sidebar
- **With `description`, `icon`, or `url`** — the tab dropdown is still shown (following Fumadocs behavior)

Set `theme.sidebar.tabs` to `false` to explicitly disable tabs.

## Groups

Groups create labeled sections within a tab. Each group has a title and a list of page slugs.

```json
{
  "groups": [
    {
      "group": "Getting Started",
      "pages": ["index", "quickstart", "installation"]
    }
  ]
}
```

Groups appear as collapsible sections with a header label in the sidebar.

## Pages

Page slugs map to MDX files in your project. The slug is the file path relative to your project root, without the `.mdx` extension.

| Slug | File Path |
|------|-----------|
| `"index"` | `index.mdx` |
| `"quickstart"` | `quickstart.mdx` |
| `"guides/setup"` | `guides/setup.mdx` |
| `"api/endpoints"` | `api/endpoints.mdx` |

### Page Ordering

Pages appear in the sidebar in the order they are listed in the `pages` array.

### Subfolders

When a page slug contains a `/`, cmdocs automatically creates a collapsible subfolder in the sidebar.

## Navbar Links

The `navbar.links` array supports 4 link types for rich navigation in the header.

### Default Link

A simple navigation link. Backward compatible with the basic `{ text, href }` format.

```json
{
  "navbar": {
    "links": [
      {
        "text": "Blog",
        "href": "/blog",
        "icon": "BookOpen",
        "active": "nested-url"
      }
    ]
  }
}
```

<TypeTable
  type={{
    text: { description: "Link display text", type: "string", required: true },
    href: { description: "Link URL", type: "string", required: true },
    icon: { description: "Lucide icon name or emoji", type: "string" },
    description: { description: "Link description", type: "string" },
    active: { description: "Active detection mode", type: "'url' | 'nested-url' | 'none'" },
    external: { description: "Open in new tab", type: "boolean" },
    secondary: { description: "Display as secondary item", type: "boolean" },
    on: { description: "Where to display", type: "'menu' | 'nav' | 'all'" },
  }}
/>

### Icon Button

An icon-only button in the navbar. Useful for social links (Discord, Twitter, etc.).

```json
{
  "type": "icon",
  "text": "Discord",
  "href": "https://discord.gg/your-server",
  "icon": "MessageCircle",
  "label": "Join our Discord",
  "external": true
}
```

<TypeTable
  type={{
    type: { description: "Must be `'icon'`", type: "'icon'", required: true },
    text: { description: "Tooltip text", type: "string", required: true },
    href: { description: "Link URL", type: "string", required: true },
    icon: { description: "Lucide icon name (required)", type: "string", required: true },
    label: { description: "aria-label for accessibility", type: "string" },
    external: { description: "Open in new tab", type: "boolean" },
  }}
/>

### Styled Button

A button-styled link in the navbar. Great for CTAs like "Get Started" or "Sign Up".

```json
{
  "type": "button",
  "text": "Get Started",
  "href": "/quickstart",
  "icon": "ArrowRight"
}
```

### Dropdown Menu

A dropdown menu containing multiple link items. Useful for grouping related links.

```json
{
  "type": "menu",
  "text": "Resources",
  "icon": "MoreHorizontal",
  "items": [
    {
      "text": "Changelog",
      "href": "/changelog",
      "description": "See what's new"
    },
    {
      "text": "GitHub",
      "href": "https://github.com/owner/repo",
      "external": true
    }
  ]
}
```

<TypeTable
  type={{

    text: { description: "Menu trigger text", type: "string", required: true },
    icon: { description: "Menu trigger icon", type: "string" },
    items: { description: "Array of link items in the dropdown", type: "MainLink[]", required: true },

/>

## Icons

Icons can be specified as:

1. **Lucide icon names** — e.g. `"BookOpen"`, `"Rocket"`, `"MessageCircle"`, `"ArrowRight"`
   - See the full list at [lucide.dev/icons](https://lucide.dev/icons)
2. **Emoji strings** — e.g. `"📖"`, `"🚀"`, `"💬"`

Icons are used in both tabs and navbar links.

## Full Example

```json
{
  "navbar": {
    "title": "My Docs",
    "github": "https://github.com/owner/repo",
    "links": [
      { "text": "Dashboard", "href": "https://app.example.com", "icon": "LayoutDashboard", "external": true },
      { "type": "icon", "text": "Discord", "href": "https://discord.gg/invite", "icon": "MessageCircle", "label": "Join Discord", "external": true },
      {
        "type": "menu",
        "text": "Resources",
        "items": [
          { "text": "Blog", "href": "/blog", "description": "Latest articles" },
          { "text": "Changelog", "href": "/changelog", "description": "What's new" }
        ]
      }
    ]
  },
  "navigation": {
    "tabMode": "auto",
    "tabs": [
      {
        "tab": "Documentation",
        "description": "Learn to use the platform",
        "icon": "BookOpen",
        "groups": [
          { "group": "Getting Started", "pages": ["index", "quickstart"] },
          { "group": "Guides", "pages": ["guides/setup", "guides/advanced"] }
        ]
      },
      {
        "tab": "API Reference",
        "description": "REST API documentation",
        "icon": "Code",
        "groups": [
          { "group": "Endpoints", "pages": ["api/overview", "api/authentication"] }
        ]
      }
    ]
  }
}
```
